# MoniHop 公开文档

本目录仅存放已完成公开审查的资料。

MoniHop 仍处于早期开发阶段。当前 `0.1.0-alpha1` 已实现显示器设备档案、鼠标与当前窗口快捷切屏，以及默认关闭的新窗口自动投放和顶部窗口投放层。应用投放支持跟随 Windows 主显示器、固定显示器和应用专属目标/布局规则；顶部投放层在拖动普通顶层窗口时提供默认投放、目标显示器选择以及保持尺寸、最大化、左半屏、右半屏布局，布局入口以图形呈现并在悬停时显示名称。“保持尺寸”会保留拖动开始时的窗口尺寸和相对位置，目标工作区较小时按原比例缩小；固定尺寸窗口会自动使用该布局，不会被强制拉伸。保留标准窗口边框的自绘标题栏窗口可以参与投放，菜单、截图遮罩、工具窗口和子窗口不会独立投放；配置只保存在本机。

安装、使用和贡献文档会在相应功能实现后，经隐私、安全和公开权利审查再加入本目录。
