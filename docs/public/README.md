# MoniHop 公开文档

本目录仅存放已完成公开审查的资料。

MoniHop 仍处于早期开发阶段。当前 `0.1.0-alpha1` 已实现显示器设备档案、鼠标与当前窗口快捷切屏，以及默认关闭的新窗口自动投放和顶部窗口投放层。快捷键页中的鼠标、窗口与鼠标组合、快捷投放、屏幕外窗口召回、自动投放开关和设置唤起均已接入真实执行能力；仅三项高频动作提供默认组合，其余动作默认未设置。每块已记录显示器可分别绑定稳定设备标识对应的投放快捷键，断开后保留配置、重连后恢复。快捷投放面板支持临时选择目标显示器和保持尺寸、最大化、左半屏、右半屏布局；召回只处理当前虚拟桌面上与所有显示器工作区完全无交集的普通窗口。应用投放支持跟随 Windows 主显示器、固定显示器和应用专属目标/布局规则；顶部投放层在拖动普通顶层窗口时提供相同四种布局。“保持尺寸”会保留窗口尺寸和相对位置，目标工作区较小时按原比例缩小；固定尺寸窗口不会被强制拉伸。菜单、截图遮罩、工具窗口和子窗口不会独立投放，全部配置只保存在本机。

安装、使用和贡献文档会在相应功能实现后，经隐私、安全和公开权利审查再加入本目录。
